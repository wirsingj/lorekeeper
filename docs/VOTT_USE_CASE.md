# Veil Of The Towers Use Case

Veil of the Towers represents the motivating pain behind Lorekeeper: a long-running AI-assisted RPG
campaign that needs more memory, continuity, and structure than a single provider chat can reliably
hold.

## Pain Points

- Long ChatGPT RPG campaigns require new chats.
- Context dumps drift over time.
- Names and places get misplaced.
- Inventories and stats get lost.
- Combat formats need repasting.
- Maps and images live in separate folders.
- Campaign canon falls behind actual play.
- Relationship context is hard to preserve.
- Unresolved plot threads disappear unless manually restated.

## Desired Role

Lorekeeper should act as the save system the campaign deserved.

It should know the active party, where they are, what they carry, who they know, what factions are
moving in the world, what lore is canon, what threads are unresolved, and how combat and prose should
feel.

When a new provider chat is needed, Lorekeeper should build a focused context pack instead of asking
the user to manually reconstruct the campaign.
