# Importers

Importers turn existing campaign continuity folders into LoreKeeper campaign bundles.

The first importer scans a local folder, reads UTF-8 text dumps, records image/document/video assets,
preserves the original source documents, and extracts a first-pass structured campaign. The extracted
state is intentionally review-oriented: it is useful as a starting point, but the raw source documents
remain attached so the user can approve, merge, or correct canon later.
