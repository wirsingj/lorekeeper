# yaiml-refresh

Read [Using YAIML](../../YAIML_GUIDE.md) for shared context, evidence, authority and retention rules; reuse it and current core memory if already loaded. “Update YAIML”, “check new YAIML” and re-init select convention refresh; “update our SoT” selects `yaiml-maintain`. Use a supplied reference first, then the recorded source or authorized workspace reference. For the public default, resolve the repository's default branch to one revision using available tools. Reuse current local guidance during ordinary work; do not poll upstream at startup.

Read [Bootstrap](../../BOOTSTRAP.md) for source resolution, acquisition, host integration and repair. Inspect worktree, current source notes and installed resource routes before writes. Identify the incoming revision/snapshot, dirty-reference changes, local adaptations and any unavailable prior base. Discovery version describes layout, not content freshness.

For each affected upstream-owned method/source, compare incoming guidance with the previously applied revision and current local file where available. Apply compatible changes in focused passages, preserving project facts, custom skills, names, headers, budgets, retention and stricter local authority. If the base is unavailable, make conservative semantic comparisons and disclose uncertainty. Preserve unknown extensions and conflicting decisions; block only dependent changes. Never replace a whole mature memory family with templates.

Repair missing/reachable bodies, notices, catalogs and host routes together. Handle upstream renames/removals by checking local callers and value; preserve adapted useful methods until their replacement is reconciled. Update the existing source note only for applied resources; retain per-resource revision exceptions or unresolved differences instead of claiming everything updated. An unchanged repeat run leaves healthy files unchanged.

For requested relocation, use Bootstrap's existing-layout procedure. Re-init offers consolidation but no answer preserves paths while refresh continues. No discovery migration, application work or delegation is implied. Check exact paths with actual consumers; quote numeric version labels without changing their spelling. Report applied/unchanged/partial/conflicting results and actual checks. Maintain project memory only for changed understanding.
