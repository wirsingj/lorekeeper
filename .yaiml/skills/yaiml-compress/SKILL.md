# yaiml-compress

Read [Using YAIML](../../YAIML_GUIDE.md) for shared context, evidence, authority and retention rules; reuse it and current core memory if already loaded. Scope the affected memory and coordinate broad cleanup with contributors. Identify necessary facts, direction, constraints, evidence limits, uncertainty, active risks/priorities, procedures and governed records. Read affected stable headers before bodies; preserve healthy unrelated sections.

Replace repeated accounts with one current account. Remove superseded claims and resolved active items; retain completion only as present capability, active constraint or a lesson naming condition and future action. Age alone cannot retire decisions or resolve conflicts. Keep rationale when useful, invent none, and never move a diary into new support files.

Inspect accumulation rules such as appending session summaries; repair them only within established authority. Governed audit/legal/incident records keep their own retention. Confirm safely retained history before relying on it. Measure whole-document words before/after; budgets are review thresholds, not deletion quotas.

Check preserved decisions, evidence, links and remaining conflicts. Report synthesis, removed redundancy, counts, growth reasons or overages and next actions. This workflow alone changes no application code. Follow `yaiml-maintain` for routine passage-level updates instead of broad cleanup.
