# AI Usage

This repository is maintained with AI-assisted development.

AI tools may be used for code generation, refactoring, debugging, tests, local scripts, documentation drafts, review notes, and generated media or assets when the project includes them.

Human review remains responsible for final decisions, accepted code, shipped assets, and published releases. AI output is not treated as independent source authority, legal advice, security assurance, or a substitute for project review.

For user-facing generated media or other material AI outputs, record the tool/provider/model, date, source inputs when relevant, and post-processing notes near the asset, release notes, or project documentation.
